title SPARC4 HWADV - Hardware Advance Mode


actor User
participant GUI
participant ICS
control DMX
participant ACS


// Operation
User->>GUI: set hardware mode
GUI->>ICS: set hardware mode
GUI->>ACS: set hardware mode
User->>GUI: set acq config
User->>GUI: start acquisition

activate GUI
GUI->>ICS: set acq config
GUI->>ACS: set acq config
GUI->>ICS: start acquisition
activate ICS
GUI->>ACS: start acquisition
activate ACS
# =============== step 1 =================
loop DONE=ON
note over ACS:in case of fast acquisitions...
activate DMX
DMX->>DMX: moving
DMX->>ACS: DONE
ACS->>ACS: wait DONE=OFF
end
# =============== step 2 =================
loop ADV=OFF
ACS->>ACS:turn ADV=ON
ACS->>DMX:ADV
DMX->>DMX:wait ADV=ON
end
# =============== step 3 =================
loop DONE=OFF
DMX->>DMX: start moving
DMX->>ACS: DONE
ACS->>ACS: wait DONE=ON

end
# =============== step 4 =================
ACS->>ACS: turn ADV=OFF
ACS->>ACS: start acquisition
